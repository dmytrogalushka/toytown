# Toy Town

A small open-world toy game made with [Rive](https://rive.app) (scripts and GPU shaders): a 32 cm toy truck in a
full-size street, walkers, toy cars to take, the police, races, an RC helicopter, yards to play in.

Play: open the site, click "Click to play" (on a phone: "Tap to play"). Keyboard and mouse, an Xbox controller, or
touch (two sticks; best sideways; on iPhone, Add to Home Screen for full screen).

This repository only holds the built game (`toytown.riv`) and its page; shared with friends for a short while.
